# Lab 4 for EDAP30
This lab consists of two parts:

- In the first part, we will learn the basics of modelling a simple, finite-state and action RL problem and how to solve it with classical Reinforcement Learning algorithms: SARSA and Q-Learning.
- In the second part, we will tackle a much more complicated problem, i.e., when the input is an image. We will implement the DQN and DoubleDQN algorithms.

The two parts can be found in two different files.
All the other files in this assignment are tools, utilities, and code required to run the part. In the notebook, these files are referenced with a hyperlink.
